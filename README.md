# 🏡 쿠사리 빌리지 v8.2 (Kusari Village) — 한눈에 들어오는 2.5D 마을 · 걸어서 안내하는 투어

쿠사리님이 만든 웹앱 14곳이 **하나의 연속된 2.5D 마을**에 모여 사는 정적 웹앱입니다.
빌드 도구·CDN·외부 라이브러리 없이 `index.html` 하나로 열립니다.

- **PC 에서는 마을 전체가 위아래 잘리지 않고 한눈에 들어옵니다.** 초기 화면과 최소 배율이 `fit`(마을 전체가 화면에 들어오는 배율)이라
  여행 지구·창작 골목·업무 광장·영감 놀이터가 한 장에 펼쳐집니다. 지도 밖으로 드러나는 자리는 **같은 잔디·강·숲을 이어 붙인 바깥 들판**이라
  베이지색 단색이나 지도 경계선이 보이지 않습니다. 모바일은 지도가 화면을 가득 채우는 `cover` 배율 그대로입니다.
- **건물을 누르면 설명 모달 없이 그 사이트로 바로 이동**합니다. 우리가 만든 자체 웹앱은 **같은 탭**, 우리가 직접 컨트롤할 수 없는 외부 사이트(예: 노션 `감사 모닝 브리핑`)는 **새 탭(`_blank`)** 으로 열려 빌리지 화면이 그대로 남습니다. 손가락으로 끌어 지도를 옮긴 직후의 손 떼임은 클릭으로 보지 않습니다.
- **본부 10곳**과 그 아래 **별관 4곳**의 계층을 지도·목록·상세에서 모두 드러냅니다.
  (예전의 `1단계`·`2단계`는 내부 구분으로만 남기고 화면에는 `본부`·`별관`으로 적습니다.)
- **낮·노을·밤이 현지 시각에 맞춰 저절로 바뀌고**(08:00~17:59 낮 / 18:00~18:59 노을 / 19:00~07:59 밤),
  **지금 이곳의 실제 날씨**(Open-Meteo)에 따라 맑음·흐림·비·눈 풍경이 달라집니다.
- 강과 다리, 오솔길, 잔디, 가로수, 꽃밭이 이어진 한 장의 마을 지도 위에서 **끌어서 이동 / 확대·축소 / 자동 투어 / 직접 걷기**를 즐길 수 있습니다.
- 클레이 미니어처 건물 14종을 투명 배경 WebP로 얹었습니다.

| 화면 채우기 | 도크의 `⌂` — 마을 전체가 보이는 최소 배율까지 물러납니다 (PC 는 마을 전체, 모바일은 화면을 덮는 cover) |
| 구역 이동 | 간판 하단 **세로 지구 바**(여행 지구 · 창작 골목 · 업무 광장 · 영감 놀이터), 우측 하단 **미니맵**(건물 점·약도 클릭) |
| 자동 투어 | 도크 `▶ 자동 투어` — **대문 앞 아바타가 정류장마다 건물 앞까지 천천히 걸어가며 안내**합니다(초당 258px, 걷기 모션·좌우 반전). 입구 → 여행 본부 → 별관 4곳 → 창작 골목 4 → 업무 광장 4 → 영감 놀이터 → 화면 채우기(16단계). 정류장에서는 건물 하이라이트만 켜고 **말풍선은 본부·별관 구분 없이 0건**입니다. 카드의 `◀ 이전`·`다음 ▶`로 건너뛸 수 있고 `■ 정지`하면 그 자리에 멈춥니다 |
| 직접 걷기 | 도크 `🚶 직접 걷기` — **마을 입구 아치 앞**에서 2등신 치비 비서가 시작합니다. 방향키·WASD, 모바일은 조이스틱·화면 탭. 건물 앞에서 `Enter` 또는 **들어가기** 버튼 = 그 사이트로 이동 |

| 날씨 | 상단 날씨 칩(`⛅ 구름 조금 1°`) — 지금 이곳의 실시간 날씨. **칩을 누르면 `자동(실시간) → 맑음 → 흐림 → 비 → 눈` 미리보기**로 바뀌어 맑은 날에도 비·눈 풍경을 구경할 수 있습니다 |

### 2) 시간대와 날씨 풍경

- **낮** `08:00~17:59` · **노을** `18:00~18:59` · **밤** `19:00~07:59` — 첫 접속 때 현지 시각으로 자동 적용됩니다.
  - **노을**: 지는 해·보랏빛 틴트·반딧불, 가로등 점등
  - **밤**: 밤하늘 톤 오버레이, 별과 달, 달빛이 비치는 강물, 건물·가로등의 따뜻한 불빛
- **날씨**는 브라우저 위치(허용 시)로 [Open-Meteo](https://open-meteo.com/)에서 현재 기온·날씨 코드를 받아옵니다.
  위치를 허용하지 않거나 4초 안에 응답이 없으면 **천안(36.815, 127.114)** 기준으로, API가 실패하면 **맑음**으로 넘어갑니다.
  - 비 → 빗줄기 낙하 + 촉촉한 톤 / 눈 → 눈송이 낙하 + 은은한 설경 / 흐림·구름 → 하늘빛 톤
- 화면 효과는 **`pointer-events:none` 캔버스 1개**로만 그립니다(아래 v3 버그 원칙 유지).

### 3) 앱 덱 (`#work`, 🎴 탭)

- `본부 11장` 카드 + `나의 여행 지도` 카드 안의 `└─ 연결된 하위 사이트 [별관 4]` 트리(접기/펼치기). 카드마다 지구·**한 줄 소개(role)**·소개 글이 함께 보입니다.
- 카드의 `열기 ↗`·하위 사이트 `열기 ↗` 는 우리 자체 웹앱이면 **같은 탭(_self)**, 외부 사이트면 **새 탭(_blank, `rel="noopener noreferrer"`)** 에서 열립니다.
- 소개·GitHub·즐겨찾기·계층(상하위)을 보려면 카드의 작은 **`ℹ️ 정보`** 버튼을 누릅니다.
  상세 시트의 열기 버튼도 같은 규칙을 따릅니다 — 자체 웹앱은 `🚀 사이트 열기`(같은 탭), 외부 사이트는 `🚀 새 탭에서 열기`(새 탭). 맨 아래 주소 링크도 같은 규칙이고, GitHub 저장소는 늘 새 탭입니다.

### 4) 계층(본부·별관) 표현

- **본부** 건물은 큰 부지·큰 스케일(300 / 258px)로 서고, 명패에는 이름과 `여행 지구 본부 · 별관 4개 연결` 같은 역할만 적힙니다.
  (예전처럼 명패에 `1단계`·`2단계` 배지를 붙이지 않습니다 — 내부 구분은 유저와 비서만 아는 값입니다.)
- **별관**은 한 단계 작은 스케일(170px)로 본부 주변에 모여 있고, **점선 오솔길 + 흐르는 방향 점**으로 본부와 직접 연결됩니다. 명패는 점선 테두리로 구분됩니다.
- 상단 입주 현황과 앱 덱·입주 폼·상세 시트에서는 **`본부`·`별관`** 으로 표기합니다.
- 상세 시트에서는 본부의 `🔗 연결된 하위 사이트` 목록, 별관의 `⬆️ 상위 허브` 배지를 볼 수 있습니다.

### 한 줄 추가하기

`data/sites.js` 의 `sites` 배열에 넣으면 코드 수정 없이 마을에 세워집니다.

```js
{ id: "my-new-app", name: "나의 새 앱", url: "https://my-new-app.vercel.app/", repo: "my-new-app",
  district: "creative", building: "cafe", tier: 1, parent: null, pos: [1700, 980],
  role: "창작 골목 · 독립 사이트", desc: "한 줄 소개", tags: ["태그1", "태그2"] },
```

- `tier` : `1`(본부·독립) / `2`(별관·본부 하위) · `parent` : `tier: 2` 일 때 상위 본부의 `id`
- `pos` : 마을 지도(2400 × 1900) 위 발밑 좌표 `[x, y]` — 생략하면 빈 부지에 자동 배치
- `district` : `travel` · `creative` · `work` · `sprout`
- `building` : `travel-hub` `hanok` `lighthouse` `lodge` `train-station` `film-lab` `atelier` `library` `privacy-vault` `archive-hall` `cafe` `greenhouse` `audit-academy` `observatory`
- `repo` : GitHub 저장소 이름 (`MinseoHaeseoFa/<repo>`) 또는 전체 URL
- `newTab` : `true` 면 **새 탭**에서 엽니다. 우리가 직접 컨트롤할 수 없는 외부 사이트(노션 등)에 씁니다.
  판정 규칙은 **`newTab === true` 또는 `repo` 없음 → 새 탭**, `repo` 있음 → 같은 탭** 입니다. 그래서 화면에서 추가하는 사이트는 주소만 넣으면 새 탭으로 열립니다.

모바일 크롬(안드로이드) GPU 합성에서 사각형 타일이 남던 원인을 지도 레이어 구조에서 제거했습니다.

- `world` 레이어의 `will-change:transform`, `border-radius:88px`, `overflow:hidden`, 큰 `box-shadow` 제거 → 지도는 화면을 덮는 단순 변환 레이어
- 지도 레이어 안의 `filter / backdrop-filter / mix-blend-mode / will-change` **전부 제거**
  - 건물 그림 `drop-shadow`, 노을 `sepia(...)` 월드 필터, 유리 효과(`backdrop-filter`) → 반투명 틴트·그림자 요소로 대체
  - 지형 SVG의 `feGaussianBlur` 필터 → 부드러운 방사형 라디안 그라디언트로 교체
- 명패·말풍선의 **역스케일(`scale(1/zoom)`) 별도 합성 레이어 제거** — 지도 좌표계 크기로 그려 한 레이어에서 함께 라스터화
- 카메라 이동 때마다 CSS 변수(`--inv`)를 다시 쓰던 매 프레임 스타일 무효화 제거, `data-zoom` 속성도 값이 바뀔 때만 갱신
- 최대 확대 2.0배로 제한해 거대 텍스처 타일링 부담 축소, 최소 배율은 cover 로 고정
- **v4 의 밤·날씨 효과도 같은 원칙**: 블렌드 모드 없이 반투명 그라디언트만 겹치고, 날씨는 `pointer-events:none` 캔버스 1개로만 그립니다.
